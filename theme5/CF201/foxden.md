# FOXDEN - An Experimental Framework for FAIR Data Management Practices

FOXDEN is a series of tools to enable FAIR Data Management Practices
and is built to be usable both by individual researchers interacting
with the tools directly and as a series of web services components
that can be embedded into applications.

The following five videos will give you an overview of the system and
how to take advantage of it. You may find the topics in CF100 to be
worth reviewing.

* [Introduction][intro]
* [Capturing Beamline Metadata at CHESS][beamlineCapture]
* [Tracking Data Analysis and Visualization Provenance][trackProvenance]
* [Publishing Scientific Data with DOIs][doi]
* [Flexible FAIR Data Infrastructure for Scientific Research][ffdisr]
